# Contributing Guidelines
## Project: MarketMaster Academy
**Code of Conduct**: Open, Respectful, Educational, Objective  

### Pull Request & Contribution Workflow
1. Fork repository and create feature branch (`feature/concept-name` or `fix/issue-description`).
2. Adhere strictly to clean architecture guidelines in [`SOFTWARE_ARCHITECTURE.md`](SOFTWARE_ARCHITECTURE.md).
3. Ensure all unit and integration tests pass before submitting PR.
4. Record all architectural decisions in [`decision.md`](decision.md) and all functional changes in [`changes.md`](changes.md).
