### 2. Automated Test-Gated Deployment Flow

No manual deployments are permitted. Every deployment follows an automated fail-closed pipeline:

1. **Pre-Deployment Test Matrix**: GitHub Actions triggers 7 parallel test suites (Lint, Frontend Vitest, Backend JUnit, Double-Entry Reconciliation, Testcontainers, Playwright E2E, Doc-Sync).
2. **Staging Smoke Probe**: Build is deployed to a staging preview container. An automated health check hits `/actuator/health` and verifies HTTP 200 response.
3. **Production Cutover**: Once staging is validated, production traffic cutover occurs automatically.
4. **Automated Rollback Trigger**: If production health verification fails within 60 seconds, an automated webhook triggers a rollback to the previous stable release.
