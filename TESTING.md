# Test Execution & Plan
## Project: MarketMaster Academy
**Frameworks**: Vitest (Web), JUnit 5 (Backend), Compose UI Test (Android)  

### Running Automated Test Suites

```bash
# 1. Run Frontend Web Tests (Unit + Component)
npm run test

# 2. Run Backend Java Tests
mvn test

# 3. Run End-to-End Playwright Tests
npx playwright test

# 4. Run Android Unit Tests
./gradlew testDebugUnitTest
```
